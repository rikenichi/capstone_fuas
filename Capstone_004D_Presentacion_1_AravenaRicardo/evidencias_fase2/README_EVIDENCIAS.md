# Evidencias Fase 2 — Proyecto APT

Este directorio reúne evidencias del desarrollo del Proyecto APT.

## Organización

- 01_planificacion: plan de trabajo, monitoreo y ajustes.
- 02_datos_etl: arquitectura de datos, ETL y validaciones.
- 03_modelamiento: modelos, métricas y explicabilidad.
- 04_software: arquitectura, frontend, backend y dashboard.
- 05_pruebas_seguridad: pruebas automatizadas, privacidad y seguridad.
- 06_despliegue_versionamiento: GitHub, Render y trazabilidad.

Cada evidencia utiliza el formato:

EVXX_nombre_descriptivo.ext
